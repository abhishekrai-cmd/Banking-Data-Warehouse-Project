# Banking Data Warehouse Project

## Project Overview

This project demonstrates the development of a banking data warehouse using SQL Server and Microsoft BI technologies.

The objective is to transform operational banking data into a structured data warehouse that supports reporting, analytics and business insights.

## Source Data

The project uses banking data containing information such as:

- Customers
- Accounts
- Bank branches
- Transactions

## Technology Stack

- SQL Server
- T-SQL
- SSIS
- SSAS
- SSRS
- Power BI

## Project Workflow

1. Understand the source database and table structures
2. Create staging tables
3. Extract and load source data
4. Perform data cleansing and transformation
5. Design dimension and fact tables
6. Implement ETL using SSIS
7. Develop analytical models
8. Create reports and dashboards

## Key Concepts

- Data warehouse architecture
- Star schema
- Fact and dimension tables
- Surrogate keys
- Incremental loading
- Data quality checks
- ETL error handling
- Data reconciliation

## Project Status

Currently working on the SQL Server and SSIS implementation.

Additional Azure Data Factory, ADLS Gen2, Python, PySpark and Databricks implementations will be added progressively.

## Disclaimer

This is a personal learning and portfolio project. No confidential company or customer data is included.
